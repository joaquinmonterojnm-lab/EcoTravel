# AI Web Creator

CONSIGNA: CREACIÓN DE UNA PÁGINA WEB CON ASISTENCIA DE IA

Objetivo

Desarrollar una página web utilizando HTML y CSS, aplicando una estructura organizada y utilizando herramientas de Inteligencia Artificial como apoyo al proceso de diseño y desarrollo.

La página deberá presentar una estructura visual clara, organizada y adaptable a diferentes tamaños de pantalla.

1. Estructura de la página

La página deberá estar compuesta obligatoriamente por las siguientes secciones:

Encabezado (Header)

Deberá contener:

* Nombre o logotipo del sitio.
* Título o nombre del proyecto.
* Menú de navegación.
* Una estética acorde a la temática elegida.

Cuerpo principal (Main)

El contenido principal deberá incluir:

* Un título principal.
* Una breve descripción o introducción.
* Un conjunto de tarjetas (cards) que presenten información relacionada con la temática.
* Cada tarjeta deberá contener, como mínimo:
* Título.
* Imagen o elemento visual.
* Descripción.
* Botón o enlace.

Se deberán crear al menos 3 tarjetas.

Pie de página (Footer)

Deberá contener:

* Nombre del proyecto o institución.
* Información de contacto o enlaces.
* Redes sociales o enlaces externos.
* Año de realización.
* Una breve leyenda de derechos de autor.

2. Temática

Cada grupo podrá seleccionar libremente una temática para su página.

Algunos ejemplos:

* Tecnología.
* Videojuegos.
* Turismo.
* Deportes.
* Música.
* Medio ambiente.
* Gastronomía.
* Educación.
* Emprendimiento.
* Cultura.

La temática deberá mantenerse coherente en todo el diseño de la página.
